# 工作台细化 v7

## 意图与约束

用户继续要求优化现有 heal 工作台。沿用已明确的简约、高级、语义图标、清楚的数据和操作反馈偏好，优化四个主要模块及共用导航。现有原生 ESM/CSS、业务能力、只读/演示边界、两级审批、私有 Site 和 Draft PR 保留；不新增依赖或模拟真实监控数据。

## 方案比较与本轮选择

- 只调整配色：改动小，但首屏信息分散和重复内容仍存在。
- **紧凑统计带、主任务区、审批与趋势辅助栏（采用，设计判断）**：保留现有页面结构和操作路径，明显改善信息密度与层级。
- 完全更换为可拖动多面板：交互和配置成本较高，超出本轮视觉细化范围。

## 具体设计

1. 首页四项指标合成约 108px 的统一统计带，数值 28px，标签 12px；保留语义图标和真实统计口径。最近六条任务约 64px/行，右栏约 286px，以待审批及结果趋势为主。移除首页重复的记录流；引擎配置压为简短入口。
2. 白色工作表面与浅灰画布形成层级；标题约 22px，正文 13px，次要文字 12px，时间和代码 11px。导航约 200px，选中态有浅靛蓝背景和明确图标颜色，主按钮保留石墨色。
3. 全部任务搜索框约 340px，筛选/显示在旁，导出靠右。桌面行高约 64px，元信息可读，批量选择工具条保留原契约。手机允许自然换行并保留独立选择及菜单。
4. 操作记录压为 80–90px 的常规事件行，长失败说明自然增高；减少类别、操作者、按钮的重复分层。任务与日志仍可独立访问。
5. 监控工具栏、统计和空态更紧凑，合并重复未接入说明；指标保持未知值，命名空间、数据源 UID/名称和配置/导出语义完整保留。
6. 静态卡片不产生类似按钮的悬停反馈。真正可点击控件使用 140–180ms 的边框/底色/1px 按压反馈，焦点可见，减少动画偏好生效。

## 验证

检查 390px 手机和桌面布局、深色主题、任务筛选/批量入口、审批阶段、图表日期/空值、监控配置、操作记录跳转、导航与键盘焦点。仅为真实行为变化增加针对性回归；执行现有完整测试、构建和格式检查，归档实际浏览器截图并更新原 Site/PR。
