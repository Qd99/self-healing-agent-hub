# v4：任务工作区与导航细节

## 目标与现状

用户指出全部任务页面缺少批量操作和筛选，布局不合理，侧栏和整体交互细节不足。现有页面只提供搜索、状态和共享的近七天过滤，48 条任务一次性呈现；首列贴边、没有分页或选择、侧栏悬停与选中不够区分，部分装饰暗示了不存在的交互。

## 设计选择

选择在现有 ESM 工作台中建立完整任务工作区，依据用户追加反馈，使用近白表面、轻分隔和按需展开控件。只给旧表格增加几个按钮不能解决选中范围与信息层级；引入全新框架没有本轮收益。保留任务行结构，加入操作工具栏、筛选面板、选中反馈与分页。

任务页独立管理时间范围，默认全部时间；首页时间选择互不影响。快捷状态视图和组合筛选覆盖引擎、问题类型、优先级、触发来源、分支、状态与时间，搜索保持字面量匹配。触发来源使用 task.metadata.triggeredBy，不使用 provenance 文本。待审批与排队展示状态互斥。已生效条件可逐项移除；过滤无结果时可一键清空。

每页 10/20/50 行，默认 10；可排序、切换密度、显示或隐藏辅助列。任务名和复选框保持独立点击目标。行内菜单提供详情、证据、审批和当前允许的操作。

选中本页与全选筛选结果分开表达；跨页保留选择，条件改变或数据源切换时清空选择。批量支持取消、重试与导出，不提供绕过逐关审阅的批量批准。决定前展示可操作任务和跳过理由，执行时重新校验模式、capability 和状态，结束后反馈逐项结果。导出采用显式可见字段白名单并防止 CSV 公式解释。

侧栏使用短导航名称和一条分隔线，移除项目卡、账户块、分组标题及连接说明。桌面可收起并记住偏好，窄屏为可退出抽屉；打开时限制背景交互与键盘焦点。底部只保留设置、主题和收起控件，连接状态集中在顶部。

任务行保留名称与 ID·类型两层，仓库/分支移到提示与详情；移除全局底部说明、任务页角标和重复数量摘要。时间范围放入筛选，排序与列设置放入显示。连接设置使用一张主卡，技术启动说明和接口契约收进原生 details。

## 约束与验收

沿用 feat/agent-console-ui 与 Draft PR #1、原有私有 Site；不修改 CI、主分支、真实执行权限。所有写行为仍仅演示内存，真实网关只读。键盘、中文输入、外部点击关闭菜单、Escape、无结果、跨页选择、混合状态批量、来源切换与 390px 窄屏均需检查。提供实际任务页和批量操作截图，更新文档与预览。
