# v9 表面与侧栏精修

## 目标与范围

用户明确要求修复页面和左侧栏生硬、重复的边框，让现有报表工作台更简约。沿用 v8 的布局、数据和交互，集中修改 CSS；本轮不改变任务、审批、监控或配置契约。

## 方案判断

考虑过仅降低边线颜色、浮动侧栏，以及用表面和留白建立层次三种方案。仅降低颜色仍保留嵌套盒子；浮动侧栏会增加外圈和阴影。实施者选择第三种：静态卡片取消整圈描边，侧栏取消外缘与分组横线，保留有操作意义的控件边界。此取舍来自用户已经提出的简约要求，不将具体视觉参数记作用户逐项确认。

官方参考：BoardUI Sidebar 的主题一致性、AffectUI Flat 结构的简洁导航，以及 Solid Glass 的中性表面与有意义的反馈。只借鉴组织原则，不引入组件库或复制付费源码。

## 样式规则

- 画布与侧栏用协调的浅灰／深灰底色；侧栏不再画右侧长线，分组用间距。
- 导航选中项采用低饱和底色、清晰字重和图标颜色，移除常驻边框与阴影；悬停和键盘焦点仍可辨识。
- 清除旧 `studio.css` 残留在 `.sidebar-bottom` 的顶线，统一处理底部工具区。
- 共享静态卡片使用白色／深灰表面、14px 圆角和轻微阴影，不以 spread 阴影模拟整圈边框。
- 首页统计带移除外框，列间使用短、淡分隔；窄屏采用留白区分两行。标题、引擎和记录图标去掉小方框描边。
- 设置来源选择和审批请求保留明确选中状态；普通项用底色和可见焦点表达交互。
- 另设轻分隔变量；不将 `--line` 全局设透明。输入框、错误状态、表格行、审批流程节点、弹窗与键盘焦点继续保留必要边界。

## 验收

检查浅色／深色首页、侧栏展开／收起／手机抽屉，以及任务、监控、操作记录、设置和审批页面的共享表面。核对导航、报表筛选和控件焦点；确认桌面和窄屏不溢出。纯样式修改不新增镜像 CSS 的测试，运行现有测试、构建及实际浏览器检查。发布原私有 Site，并同步原 Draft PR，最终来源见验收记录和 PR 描述。
