# v10 · 连接设置与操作记录

## 目标与授权

用户要求重新设计连接设置和操作记录，使其与工作台一致，并移除顶部任务搜索与演示任务相关内容。本轮在已有 `feat/agent-console-ui` 分支和原私有 Site 上直接完成修改、验证与发布。

## 设计决定

沿用浅灰画布、14px 无外描边白色面板、统一按钮/输入/状态组件与 Lucide 图标。连接设置使用一张紧凑服务列表，管理服务、Grafana、Prometheus 各一行；必要的连接详情按需展开，配置入口继续进入已有监控配置页。主界面不铺开接入教程、技术说明或数据来源切换卡片。

操作记录使用固定列节奏的紧凑表格：操作、关联对象、操作者、时间、记录级别。记录级别只依据服务返回的 `level`，不将普通信息推断为成功。点击操作打开复用现有 dialog 的详情抽屉，保留完整消息、原始时间和关联任务/日志入口。局部搜索、类别、时间筛选、分页和当前筛选导出继续可用。

顶部只保留项目位置与移动端导航。默认发布常规同源 API 构建，取消页面上的演示模式入口和默认虚构任务；未连接时保持 `snapshot: null`，显示明确空状态，绝不将示例配置改名为真实配置。开发者显式 `?demo=1`/`build:demo` 仅作为离线测试夹具保留，其数据来源仍必须可辨认。

## 方案比较

1. 继续缩小原有来源切换卡片：改动少，但保留了多层描述、重复状态与演示入口，不满足反馈。
2. 每项连接各做独立大卡片：容易扩展，但这里只有少量服务，会放大稀疏感与不一致。
3. 简短服务列表 + 详情展开；记录紧凑表格 + 抽屉：采用此方案。该实现选择依据用户已明确的简约与统一要求，由实现者决定。

## 验收

- 顶部不含全局搜索、演示标记；默认站点不加载虚构任务或操作记录。
- 连接列表与全站面板、按钮、焦点、圆角、明暗主题一致；草稿不得标为已连接。
- 记录筛选/分页/导出范围一致；未知操作者、时间、级别保留诚实回退。
- 记录详情可用键盘打开、Escape 关闭、返回触发处；任务缺失时不生成无效跳转。
- 390px、1024px、桌面均无页面横向溢出，明暗主题正常。
- 管理 API、真实执行/审批/回滚能力边界保持不变；不增加凭据或外部连接的写操作。
