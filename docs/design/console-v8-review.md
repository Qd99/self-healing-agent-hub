# 工作台 v8：报表首页与验收记录

2026-11-09。本轮按用户“增加报表数据、缩小最近任务、突出数据图标”的要求重排首页。任务指标与四类报表成为主要内容，最近任务保留为紧凑入口。沿用原生 ESM／CSS、Lucide 图标、共用控件和现有快照契约，没有新增图表库或后端接口。

实施范围见 [v8 设计说明](../superpowers/specs/2026-11-09-dashboard-reports-v8-design.md) 和 [实施计划](../superpowers/plans/2026-11-09-dashboard-reports-v8.md)。本记录分别列出实现内容、独立审查、最终集成验收与 Site 发布结果。

首页不再重复完整审批流程卡；完整节点证据、代码变更、两级决定与跨轮次记录仍在审批中心。其他模块继续沿用共用导航、按钮、状态、筛选、焦点和主题组件。

## 2. 报表数据口径

### 统一时间范围

新建 [analytics-model.js](../../apps/console/public/analytics-model.js)，由 `getDashboardAnalytics(tasks, {days, now})` 返回 `days/tasks/metrics/daily/statuses/types/engines`。支持 1／7／30 天，无效范围回退为 7 天；一次渲染中的指标、报表和最近任务共用同一次过滤。输入数组与任务对象不被修改。

时间范围按 `Asia/Shanghai` 日历日期计算，包含当天，排除未来和无效创建时间。日序列补齐空缺日期。每日的已完成与失败是**该日期创建的任务当前结果**，并非该日实际完成或失败的任务流量；其他状态统一进入趋势的「其他」部分。

### 比例与耗时

- 修复成功率为 `completed / (completed + failed)`；运行、排队、取消、跳过不计入分母。分母为零时显示 `—`。
- 状态图、类型排行和引擎任务量占比的分母为当前范围全部任务。状态构成中待审批优先，与排队互斥，未知状态不会丢失。
- 类型排行的条形长度相对于数量最多的分类；右侧百分比仍以总任务量为分母。
- 平均耗时仅纳入已完成或失败且耗时为有限非负数的任务。规则复用 `getMetrics`：结果耗时缺失时才尝试使用状态起止时间，显式非法耗时不改算为零。没有有效样本时显示 `—`。
- 缺失类型／引擎归入 `unknown`，与该字面 ID 合并；无法准确对应任务筛选的聚合项只显示数据，不提供下钻。其余陌生字符串保留为各自分组。

例如现有 48 项虚构演示数据中，42 项已完成占全部任务的 **87.5%**，成功率则为 `42 / (42 + 3)`，约 **93.3%**。环形图中心展示任务总量，避免将这两个不同分母的百分比混用。

### 引擎数据含义

引擎表现按当前范围中实际分配给每个 `engineId` 的任务聚合，不用引擎配置数量或 `configured` 状态推断在线率。不同引擎的任务类型、数量和难度可能不同，成功率与平均耗时只描述各自任务样本，不能作为公平性能排名。

所有线上演示任务、结果、耗时和图表均来自明确标记的虚构快照，不能称为真实 Agent 运行数据。本轮未增加 CPU、Token、费用节省、历史环比或其他没有数据来源的指标。

## 3. 分类下钻与交互

状态、可定位类型和引擎通过 `dashboard-filter` 进入全部任务。任务控制器应用“首页当前时间范围＋对应唯一分类条件”，清理旧关键词、其他条件、跨页勾选、批量计划与结果、行菜单和浮层；页码回到第一页，排序恢复为最新创建。每页条数、行密度与显示列偏好保留。

「查看任务」与最近任务的「查看全部」使用当前首页范围下的全部任务，不额外带入最近任务的小视图。未知或不合法维度不能改变任务筛选。该操作只改变本机视图，不执行任务、不提交审批、不修改服务端配置。

图表日柱支持悬停和键盘读数；分类按钮使用共用反馈与可见焦点。没有数据时显示空态，不绘制有含义的伪造曲线。深色与窄屏沿用语义颜色和响应式布局，减少动画偏好保留。

## 6. 当前接入边界

真实配置 API 继续只读，实际任务执行器尚未接入；已列出的真实任务写接口返回 `501`。演示创建、取消、重试、审批和规则变更只作用于页面内存。分类下钻没有扩展这些能力。

Grafana 继续提供命名空间、Prometheus UID／名称、变量映射、本机草稿、外部链接和模板导出。远端连通性、嵌入面板和真实指标查询尚未验证或接入，不能用首页任务报表替代 Prometheus 监控数据。

完整使用说明见 [工作台指南](../console-guide.md)，接口边界见 [API 契约](../console-api.md)，监控字段与导出规则见 [监控接入说明](../monitoring-integration.md)。
