# 管理台 v6：任务优先与统一交互

2026-11-09，本轮更新工作台、全部任务、监控面板与操作记录，沿用现有 Site、原生 ESM/CSS 与业务契约。Site 继续提供明确标记的交互演示；真实执行器和 Grafana 连通性仍未接入或验证。

## 四个模块

| 模块     | 本轮调整                                                                                                                                                                     |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 工作台   | `uiMetric` 统计卡采用语义图标与轻边框，首屏突出六条最近任务；辅助栏保留待审批、最近记录和引擎配置，补充任务结果趋势。完整审批流仍在审批中心。                                |
| 全部任务 | 类型图标、标题打开箭头、独立复选框、选中行边缘和工具栏按钮强化操作入口；筛选、跨页选择、批量确认与导出范围保持原样。分页回到文档流，避免遮挡末尾任务；「每页」标签保持单行。 |
| 监控面板 | 统一范围、时间及配置工具区，用数据卡区分已配置命名空间与尚未查询的指标；保留配置草稿、外部打开和 JSON 导出。                                                                 |
| 操作记录 | 单一边框工作区、日期分组与记录数，突出动作、操作者及关联目标；任务详情和执行日志各有明确按钮，支持原有筛选与导出。                                                           |

## 统一反馈

按钮、图标按钮、页签、展开控件与输入框共用悬停、按压、选中和焦点样式；边框与阴影保持克制。`interaction.js` 在页面重绘后定位对应控件并显示短暂点击反馈，不改写业务结果，也不把动画当作成功提示。手动刷新另行报告成功或失败，禁用控件不触发反馈；减少动画偏好继续生效。

浅色、深色、折叠侧栏和手机抽屉沿用同一套 token。带复选框和菜单的任务行保持独立点击目标。

## 数据口径

- 首页统计与趋势都来自当前快照和所选时间范围。趋势按北京时间的**任务创建日期**归组，展示该组任务的当前完成／失败结果，不是当天实际完成量。
- 成功率为 `completed / (completed + failed)`；平均耗时仅包含已完成或失败且耗时有效的任务。无可计算数据时显示 `—`，列表和日期组计数由实际筛选结果计算。
- 演示任务与结果为虚构样例。监控的已配置命名空间数来自配置；可抓取目标与抓取异常仍显示 `—`。配置有效不代表 Grafana 连通、Prometheus 已查询或 Agent 健康；范围选择不修改实际监听范围。
