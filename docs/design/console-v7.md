# 工作台 v7：紧凑统计、任务主区与明确反馈

2026-11-09，本轮基于 v6 细化工作台、全部任务、监控面板、操作记录及共用导航。实现继续使用原生 ESM/CSS 和既有快照契约，没有新增依赖；任务与两级审批能力、只读 API 和演示边界继续保留。本记录分别列出已实现的变更、代码验证、实际浏览器观察与 Site 发布结果。

设计约束与实施范围见 [v7 设计说明](../superpowers/specs/2026-11-09-console-refinement-v7-design.md) 和 [实施计划](../superpowers/plans/2026-11-09-console-refinement-v7.md)。

## 2. 交互与重复筛选修复

按钮、图标按钮和页签继续使用共用的边框、底色和轻微按压反馈。既有 `interaction.js` 在原生点击引起重绘后定位对应控件，提供短暂反馈；结果仍通过业务状态和提示确认。静态容器保持稳定，焦点样式与 `prefers-reduced-motion` 适配继续生效。

常规页面导航在渲染后将焦点移到 `#main-content`，配合页面已有的跳转入口。任务搜索在导航后聚焦输入框，任务筛选与浮层继续通过原有控制器恢复对应控件焦点。

本轮修复任务控制器中重复应用同一筛选条件会丢失选择的问题：

- 再次点击当前状态、提交未变化的详细筛选，或在条件已为默认值时重置筛选，保留已选任务、当前页码和批量结果。
- 搜索或筛选实际变化时，仍回到第一页、清空旧选择与批量结果，并在原先存在选择时提示。
- 未变化的条件仍经过正常重绘路径；浮层关闭和焦点恢复沿用原有规则，不影响复选框、任务名称、菜单和批量入口各自的职责。

四项针对性回归位于 [console-task-controller.test.mjs](../../tests/console-task-controller.test.mjs)。批量取消与重试仍需要演示模式、对应 capability 和合适的任务状态；两级审批仍逐关处理，没有新增批量批准。

## 3. 数据口径与接入边界

首页统计和趋势使用所选的今天、近 7 天或近 30 天范围，按北京时间的任务创建日期归组。趋势中的完成／失败数量表示该日期创建的任务当前结果。近 7 天和近 30 天压缩为起、中、末三个可见日期标签，仍保留每一天的分组和可聚焦数量提示。

成功率继续为 `completed / (completed + failed)`。平均耗时只使用已完成或失败且有有效耗时的记录；缺失耗时不作为零计入平均值。没有可计算数据时指标显示 `—`，没有已完成或失败任务时趋势显示明确空态。日期、统计与持续时间计算沿用 [model.js](../../apps/console/public/model.js) 的规则。

监控的可抓取目标和抓取异常保持 `—`，已配置命名空间数来自配置。配置有效仅表示字段通过校验，连接与指标仍未验证；页面不查询 Prometheus、不嵌入远端面板，也不把抓取成功解释为 Agent 健康。示例 `.invalid` Grafana 地址的外部打开入口保持禁用。

「保存到本机」仍生成按模式与项目隔离的草稿，存储不可用时明确说明仅本次会话有效；不会写回服务端或修改实际监听范围。配置和仪表盘导出保持原有语义，接入步骤见 [Grafana 与 Prometheus 说明](../monitoring-integration.md)。

真实管理 API 继续只读，尚未连接实际任务执行器；真实任务写接口返回 `501`。演示中的创建、取消、重试、审批和规则变更只修改页面内存，重新加载页面后重置。具体能力以 [工作台指南](../console-guide.md) 和 [API 契约](../console-api.md) 为准。

## 5. 发布与浏览器验收

### 实际浏览器观察

- 1363px 桌面检查工作台、全部任务、监控面板和操作记录，另行检查并归档深色首页；四模块同时在 390px 和 1024px iframe 预览中实际截图检查，均无页面级横向溢出。
- 手机导航可以打开，选择模块后抽屉正常关闭。
- 监控「配置接入」切换到接入表单，并将焦点移到对应页签。
- 任务第二页选择十项后，再次点击当前「全部」仍保留第二页和十项选择；改变筛选条件后清空选择。
- 首页「查看全部」导航到任务页后，焦点落在 `main-content`。
