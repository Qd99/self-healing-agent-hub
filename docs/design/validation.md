## 视觉与交互结果

v3 使用蓝灰背景、较实的白玻璃面板、细边缘高光、柔和阴影和带色底座的 Lucide 图标。首页展示轻量指标、自愈流程、任务列表、审批入口和引擎状态。独立审批中心包含请求列表、流程画布、节点详情、候选 diff、历史记录和决定表单。

流程画布默认适应桌面面板宽度，保留缩放按钮；窄屏保留可横向滚动的可读节点。当前审批节点有呼吸描边，指向当前节点的连线有方向动画，运行中的演示引擎有微型波形，按钮有按压反馈。`prefers-reduced-motion` 会停止循环及非必要动画。

## 浏览器检查

使用实际 Chrome，以及 390px 宽的独立 iframe 视口；通过可见控件操作，没有注入脚本改变审批状态。

| 检查 | 已观察结果 |
| --- | --- |
| 首页、审批入口与节点图 | 图标、六节点和分支连线显示完整；桌面默认适应可用宽度 |
| 点击质量验证节点 | 节点详情切换到检查证据，可返回当前审批 |
| 第一关通过 | 代码审阅完成，执行授权变为当前关卡，请求仍待审批 |
| 第二关通过 | 显示两级审批完成和等待执行器；未伪造修复完成 |
| 空原因拒绝 | 显示 1–500 字原因校验，焦点回到输入框，状态不变 |
| 填写原因后拒绝 | 显示已拒绝，下游阻塞，原因留在节点详情与历史 |
| 重新发起审批 | 轮次增加，回到代码审阅；原拒绝记录和重新提交说明同时保留 |
| 候选 diff 与证据 | 增删行正确显示，证据抽屉可打开，返回入口指向审批中心 |
| 深色主题 | 图标、状态、流程、表单和背景层次可辨 |
| 390px 窄屏 | 页面本身无水平溢出；请求列表和节点图在各自区域横向滚动；拒绝与重新提交表单可操作 |

独立代码审查发现取消已授权任务时被误投影为“未接入”。已修复为明确 `cancelled` 状态：保留已通过的关卡与证据，停止后续操作；对应失败用例先复现后通过。其余有限审查未发现需要报告的高置信实质问题。
