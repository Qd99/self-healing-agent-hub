## 浏览器检查

使用实际 Chrome 页面与 390px 宽的独立 iframe 视口进行检查，没有通过脚本注入绕过 UI。

| 流程 | 已观察结果 |
| --- | --- |
| 从全部任务发起模拟巡检 | 新增 pending 任务，导航到工作台后详情保持打开 |
| 取消和重试 | 取消后显示 cancelled；重试生成新 ID，保留原任务 |
| 审阅证据与批准 | 可查看前后状态及检查项；批准后仍排队，不伪造执行完成 |
| 搜索 `AGT-2047` | 正确显示单项任务 |
| 从演示切到不可用的同源服务 | 显示明确连接错误，任务数据清空，没有自动切回演示 |
| 深色主题 | 保留层级、对比和 diff 状态颜色 |
| 390px 窄屏 | 侧栏隐藏；“查看变更”可打开完整详情，diff 可横向滚动 |
| 跳至主要内容 | 在规则页保持 `#rules`，焦点进入 main-content |
| 原生详情对话框 | 打开后聚焦关闭入口，关闭时回到可用触发点或主内容 |

独立代码审查确认了配置白名单、真实模式 capability、来源切换竞态、HTML 转义、时区统计及原有框架契约。审查发现的创建后详情误关闭、skip-link 误路由、移动审阅入口隐藏已修复；移动侧栏退出焦点序列，运行与排队数量口径已统一。
