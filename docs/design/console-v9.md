# 工作台 v9：表面与侧栏精修

2026-11-09。本轮针对用户“页面边框和左侧栏边框生硬、不够简约”的反馈，统一静态表面、导航和小图标的视觉边界。保留 v8 的报表布局、四条最近任务及全部交互，仅修改 `ui.css`、`navigation.css`、`dashboard.css` 和 `settings.css`，没有改变 JavaScript、数据契约或依赖。

实施范围见 [v9 设计说明](../superpowers/specs/2026-11-09-surface-navigation-v9-design.md) 与 [实施计划](../superpowers/plans/2026-11-09-surface-navigation-v9.md)。

## 1. 原有边框来源

旧版侧栏同时包含右侧长线、导航选中框、分组线、设置区顶线与底部工具区顶线。设置区还继承了 `studio.css` 的 `.sidebar-bottom` 顶线，后加载的导航规则没有清除该边框。页面中静态卡片、统计带、图标底座和选中控件又重复使用整圈描边，形成过多嵌套轮廓。

v9 用底色、留白和轻阴影区分静态区域，给内容分隔、表单、流程图及焦点保留各自用途明确的边界。没有把全局 `--line` 改为透明。

## 2. 统一样式规则

| 区域       | v9 处理                                                                                       |
| ---------- | --------------------------------------------------------------------------------------------- |
| 页面与侧栏 | 浅色、深色下分别使用相同画布底色；移除侧栏外侧长线与顶栏底线。                                |
| 导航分组   | 取消横线，用垂直间距组织工作空间、管理配置及底部设置入口。明确清除旧 `.sidebar-bottom` 顶线。 |
| 导航选中态 | 无常驻描边或阴影；由 `--nav-active` 底色、字重与图标色表示当前页面，悬停采用独立底色。        |
| 静态面板   | 共用无整圈描边的白色／深灰表面、14px 圆角和轻阴影；兼容既有模块表面。                         |
| 首页统计带 | 移除外框，以 `--line-soft` 绘制短分隔；窄屏两行通过留白区分。                                 |
| 图标       | 指标保留浅色底，报表标题、引擎、最近任务和列表图标去除小方框描边。                            |
| 来源选择   | 普通项用浅色填充；当前项采用主题色浅填充、左侧 3px 标识与文字／图标色。                       |
| 轻量按钮   | Ghost 和图标按钮悬停通过底色与颜色反馈，不绘制额外外圈。                                      |

侧栏仍支持桌面收起、收起后的名称提示、手机抽屉与关闭入口。共享卡片样式同时作用于任务、操作记录、监控、设置和审批页面，避免仅首页去框而其他模块保留另一套静态表面。

## 3. 保留的交互与可访问性

- 输入框、下拉框和文本域的可辨识边界，以及聚焦和校验错误样式。
- 表格行分隔、页签选中标识、任务选择与批量操作状态。
- 审批流程节点、连接点、选中状态和人工关卡语义。
- 弹窗、浮层与 tooltip 的层级，导航与控件的可见键盘焦点。
- 浅色、深色和 `prefers-reduced-motion` 适配，以及现有点击反馈。

首页继续提供任务趋势、状态构成、问题类型、引擎表现四类报表；最近任务仍为最多四条。时间切换、统计口径、分类下钻、筛选清理、审批及任务操作逻辑均沿用 v8。数据含义见 [v8 报表记录](console-v8-review.md)。

### 实际浏览器观察与修复

- 桌面展开时，侧栏、当前导航项、设置区、工具区和顶栏的计算边框均为 `0px`。共享模块卡片无整圈描边；任务行与审批节点仍保留 `1px` 功能边界。
- 桌面收起侧栏宽度为 `64px`；导航名称 tooltip 可以显示，键盘焦点轮廓仍为 `2px`。输入框保留 `1px` 边框与 `2px` 焦点轮廓。
- 390px 预览中，首页可用宽度和滚动宽度均为 `375px`；手机抽屉宽 `224px`、边框为零，点击「连接设置」后关闭。1024px 预览中，两项宽度均为 `1009px`，没有页面级横向溢出。
- 深色首页完成视觉检查。连接来源选项曾被旧深色规则重新加上整圈描边；删除该残留后，计算边框为透明，左侧 `3px` 当前来源标识保留。
- 手机无障碍树检查发现「去审批」旧样式通过 `display: none` 隐藏文字，导致按钮缺少名称。改用视觉隐藏后，按钮的可访问名称为「去审批」，按名称可定位到一个按钮；没有修改 JavaScript。

## 5. 接入边界

在线 Site 继续使用明确标记的虚构演示任务。真实配置 API 仍只读，具体执行器尚未接入，真实任务写接口返回 `501`；演示操作仅作用于页面内存。

Grafana 继续提供命名空间、Prometheus UID／名称、变量映射、本机草稿、外部打开与模板导出。远程连通性、嵌入面板和真实指标查询仍未验证或接入。本轮样式修改没有扩展这些能力。

完整功能与使用说明见 [工作台指南](../console-guide.md)，真实接口边界见 [API 契约](../console-api.md)，监控字段与导出规则见 [监控接入说明](../monitoring-integration.md)。
